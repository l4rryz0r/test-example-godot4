Небольшой 2D-платформер о побеге из неоновой лаборатории. Прототип для тестового задания: один уровень, шесть стражей, ближний бой и выход в конце маршрута.

## Управление и цель

| Действие | Клавиши |
| --- | --- |
| Влево / вправо | A / D или стрелки |
| Прыжок | Space, W или стрелка вверх |
| Удар | J или левая кнопка мыши |
| Пауза / продолжить | Esc |
| Начать заново | R |
| Включить / выключить звуки | M |

Дойдите до светящегося шлюза справа. Уничтожать всех стражей необязательно; счётчик показывает результат. Прыжок выше, если удерживать кнопку. Жёлтый восклицательный знак предупреждает об ударе врага: отступите или прервите замах своим ударом. Не подходите вплотную — контакт тоже наносит урон. Провалы смертельны.

У игрока 5 HP, у каждого стража 3 HP. После получения урона игрок неуязвим 0,85 секунды. После смерти показывается Game Over, и через 3 секунды сцена автоматически перезапускается; кнопка и R позволяют начать раньше. На финише показаны время и число побеждённых врагов.

## Соответствие заданию

| Требование | Реализация |
| --- | --- |
| Godot 4, GDScript | Типизированные игровые скрипты, без сторонних аддонов |
| Уровень TileMap | Сохранённый `TileMapLayer` с `TileSet`, атласом 32 × 32 и физическими полигонами |
| Старт, финиш и камера | Старт слева, Area2D-шлюз справа, Camera2D со сглаживанием и границами |
| Движение и прыжок | CharacterBody2D, ускорение, переменная высота, coyote time и буфер прыжка |
| Ближний бой | Отдельные Area2D hitbox/hurtbox, маски команд, одно попадание за взмах |
| Урон и смерть | Компонент Health, неуязвимость, отбрасывание, Game Over и перезапуск |
| ИИ | PATROL → CHASE → WINDUP → RECOVER; HURT прерывает атаку; DEAD выключает коллизии |
| Край и обнаружение | RayCast2D проверяет опору; Area2D обнаруживает игрока; луч проверяет прямую видимость |
| Реакция на попадание | AnimationPlayer с hurt/RESET, вспышка, частицы, звук, шкала HP врага |
| UI | HP игрока, счётчик врагов, прогресс до выхода, время, пауза и итоговые экраны |

`TileMapLayer` — современная замена устаревшего `TileMap` в Godot 4.3+. Уровень можно редактировать кистью непосредственно в редакторе. Враги не прыгают между платформами: они преследуют в пределах достижимой поверхности и останавливаются перед пропастью.

## Структура и решения

- `actors/player.tscn`, `player.gd` — управление и реакции игрока.
- `actors/enemy.tscn`, `enemy.gd` — переиспользуемая сцена стража и конечный автомат.
- `actors/actor_visual.gd` — геометрическая графика роботов и процедурная анимация ног/оружия. Физические формы не масштабируются.
- `combat/` — типизированное описание попадания, здоровье, хитбокс и зона получения урона. Окно атаки ограничено временем; вне него хитбокс не мониторит пересечения.
- `world/main.tscn`, `main.gd` — сборка уровня, соединение сигналов, победа/смерть и перезапуск. UI не вызывается из контроллеров персонажей.
- `world/level.tscn` — сохранённая сетка платформ и TileSet; генерация в игре не нужна.
- `ui/hud.tscn`, `hud.gd` — интерфейс на Control/Container, отдельно от мира.
- `effects/`, `audio/`, `assets/` — частицы, оригинальные синтезированные звуки и SVG-тайлы.
- `tests/integration.gd` — проверки реальных сцен и физики, включая полное прохождение через действия ввода.
- `tools/` — необязательные инструменты авторинга и визуальной проверки, не подключённые к игровой сцене.
